# commande git

Listes de commandes git

## commande git init
- Permet d'initialiser un repertoire

## commande git add .
- Permet de tracquer les fichiers d'un repertoire

## git commit
- permet d'enregistrer une modificationen local

## git push 
- permet de pousser les modifications en ligne 

## git log --oneline 
- permet de lister les modifications effectuées en local

## git status
- permet de verifier le status d'un repertoire
## git diff +id
- permet de comparer deux commits

## git reset --hard + id
- permet de faire un rollback d'une version à l'autre

## git branch
- permet de creer une branche 

## git checkout 
- permet de se deplacer d'une banche à l'autre
- permet avec l'option -b de simultanement creer et basculer sur une branche

## git pull
- permet de recupérer les modifications effectuées en ligne au niveau local.

## git rebase
- permet de recuperer les modifications de la branche mère sur la branche fille
- les modifications de la branche mère sont placées en dessous des modifications de la branche courante (fils)

## git merge
- permet de recuperer les modifications des branches fils et de les ramener sur la branche mère
