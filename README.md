# commande git

Liste de commandes git

## commande git init
- Permet d'initialiser un repertoire

## commande git add .
- Permet de tracquer les fichiers d'un repertoire

## git commit
- permet d'enregistrer une modificationen local

## git push 
- permet de pousser les modification en ligne 

## git log --oneline 
- permet de lister les modification en local

## git status
- permet de veifier le status d'un repertoire
## git diff +id
- permet de voir les differences entre les versions

## git reset --hard + id
- permet de faire un roolback d'une version à l'autre
